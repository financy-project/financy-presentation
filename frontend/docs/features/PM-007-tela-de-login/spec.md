## Description

Permitir que usuários existentes autentiquem-se na aplicação com e-mail e senha.

## Users

Usuários finais já cadastrados

## Acceptance Criteria

* [ ] Formulário exige e-mail e senha (validação obrigatória)
* [ ] Login com credenciais válidas redireciona ao dashboard
* [ ] Credenciais inválidas exibem mensagem de erro
* [ ] Opção "esqueci minha senha" visível na tela
